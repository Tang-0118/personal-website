# 简历工作区

**成品是网页版**（双栏、带标签），但**文字在一个 Word 母版里改**——网页版本身是 HTML/CSS，Word 存不了它的版式，所以这里的做法是：

```
resume.docx（Word 母版：只放文字）  ──cv_from_docx.py──►  ../cv.html（网页版）
                                                            │
                                                       打印成 PDF
                                                            ▼
                                            resume.pdf（一页，下载按钮指向它）
                                            resume-web.pdf（未压缩，两页）
```

## 日常：改文字 → 出网页版 PDF

1. 用 Word 打开 `resume.docx`，改文字（加粗也会被带到网页版），保存；
2. 跑一条命令：

```powershell
powershell -File resume\make_pdf.ps1
```

它会：读 Word → 重建 `..\cv.html`（就是 https://kexin.uno/cv.html ）→ 生成 `resume.pdf`（网页排版压成一页 A4）和 `resume-web.pdf`（未压缩两页）。推送到 GitHub 后线上就更新了。

## 母版的写法（脚本按这个约定读）

| 位置 | 怎么写 |
| --- | --- |
| 抬头 | 第一行姓名；`求职意向：…` 一行；再一行写定位语；`联系方式：电话 · 邮箱 · GitHub: 用户名` |
| 板块 | 单独一行写 `[板块名]`，脚本认这几个：`[教育背景]` `[技术技能]` `[获奖与认证]` `[项目经历]` `[实践经历]` |
| 条目 | 一行用 **Tab** 分隔「名称 + 时间」，例如 `湖南大学	2024.09 — 2028.06` |
| 项目标题里的标签 | 写成 `无人车间人形安全防护系统（课题组校企合作 · 已商用上线）	2026 — 至今`，括号里的内容会变成网页上的小标签 |
| 项目小节 | `一句话：…`、`概述：…`、`获奖：…`、`技术栈：A、B、C` |
| 要点 | 以 `•` + **Tab** 开头，写成 `•	小节标题：正文`；小节标题会按网页样式加粗 |
| 技能 / 获奖 | 板块里一行一条，技能写成 `标签：chip1、chip2`，获奖里的**加粗会在网页版保留** |

> 换行、空格随便调，脚本只按上面的结构提取文字；版式一律由网页样式决定，所以在 Word 里怎么排版都不影响成品。
> 万一改乱了想重来：`python build_master.py` 会用网页版当前的数据重新生成一份母版（会覆盖 `resume.docx`）。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `resume.docx` | **Word 文字母版**（内容唯一来源，随便改） |
| `resume.pdf` | 投递用：网页排版压成一页 A4（下载按钮指向它，文字可选可搜索） |
| `resume-web.pdf` | 同一份内容、未压缩的网页排版版（A4 竖版 2 页） |
| `make_pdf.ps1` | **一条命令**：Word → `cv.html` → 两个 PDF |
| `cv_from_docx.py` | 读 Word 母版，生成网页版 `../cv.html` |
| `build_master.py` | 由网页版数据反向生成 `resume.docx`（重置母版用） |
| `build_cv_html.py` | 网页版的模板与渲染器，也保存着初始内容与打印样式 |
| `word_to_pdf.ps1` | 底层工具：Word → PDF（需要时才用） |
| `pdf_to_png.py` / `img_to_pdf.py` | PDF 转 PNG 检查排版 / 截图转 A4 PDF |
| `moyuin.css` | 在线简历的样式源 |

以 `_` 开头的都是中间产物，可随时删。

## 想换排版

版式全在 `build_cv_html.py` 的 `PRINT_OVERRIDES`（打印样式）和 `moyuin.css` 里；`PDF_SCALE`（脚本里是 0.85）控制「压到一页」的缩放比例，0.86 是仍能装进一页的最大值。
